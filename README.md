To run this you should have Prerequisites of

1. Node.js v16.14.1 
2. npm ≥ 8.x 
3. MongoDB
4. Cloudinary account

env file will be shared to you on whatsapp. Create a mongodb database on mongodb atlas. You can give the name to the database and collection as per wish or as per given into the env file. 

Steps to do:

1.) Clone the repository (You know how to do that)

2.) at the terminal run 'npm install'

3.) you should have a cloudinary acc the steps to create that are as follows
i) Create a Cloudinary Account
Go to 👉 https://cloudinary.com
Click Sign Up for Free
You can sign up with email + password OR use Google/GitHub.
Verify your email if required.
ii) Access Your Dashboard
After signing up & logging in, you’ll land on your Cloudinary Console (Dashboard).
It looks something like this:
Cloud Name: your_cloud_name
API Key:    1234567890...
API Secret: ****************

4.) Then firstly connect your database
5.) goto vscode and create anew terminal and write 'cd backend' and then run it using 'npm run dev'.
6.) create a new terminal again and write 'cd frontend' then run it using 'npm start'

Bus fir done!! 👍🏻
